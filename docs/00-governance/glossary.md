# 青禾流转业务术语

## 组织与用户

| 中文术语 | 代码术语 | 定义 |
|---|---|---|
| 高校/学校 | `University` | 数据隔离边界；用户只能操作本校业务 |
| 校区 | `Campus` | 学校内部地点；同校不同校区允许流转 |
| 在校学生 | `Student` / `student` | 可发布、借用、购买、领取、捐赠和评价的师生账号 |
| 公益管理员（回收） | `StationManager` / `station_manager` | 负责物品接收、回收确认、公益物资核验和回执 |
| 平台管理员 | `PlatformAdmin` | 管理高校数据、学生名单、角色、审核和异常 |
| 校级管理员（预留） | `UniversityAdmin` / `university_admin` | 账号由平台管理员导入的本校管理身份；首版不开放管理功能 |
| 回收/公益站点 | `Station` | 设在校区内、承担回收验收或公益物资核验的线下服务点 |
| 学生名单记录 | `StudentRegistryRecord` | 管理员导入的校内学生核验记录，包含学号、学院和校区等字段 |
| 名单导入批次 | `StudentImportBatch` | 一次 CSV 名单导入的操作者、摘要、成功行和失败行记录 |
| 公益管理员站点授权 | `StationManagerAssignment` | 将公益管理员（回收）账号限定到具体站点和有效期限的关系 |
| 登录身份 | `LoginRole` | 登录前选择的在校学生、公益管理员、平台管理员或校级管理员入口 |
| 登录账号 | `LoginName` | 非学生管理员登录使用的平台内账号名；学生使用学号和手机号 |

## 物品与流转

| 中文术语 | 代码术语 | 定义 |
|---|---|---|
| 物品 | `Item` | 可被共享、出售、赠送或回收的实体记录 |
| 流转方式 | `CirculationMode` | `borrow`、`sale`、`give`、`recycle` |
| 流转申请 | `CirculationRequest` | 用户对某物品发起的借用、购买、领取或回收请求 |
| 交接 | `Handover` | 双方确认物品转移的过程 |
| 交接码 | `HandoverCode` | 用于验证交接的一次性凭证，首版保存在 `handover_records` 中 |
| 归还 | `Return` | 借用结束后，借用人将物品交还出借人的流程 |
| 逾期 | `Overdue` | 超过约定归还时间的状态 |
| 争议 | `Dispute` | 对损坏、逾期、描述不符或交接结果存在异议 |
| 活动申请 | `ActiveRequest` | 尚未拒绝、取消或完成、仍占用物品的流转申请 |
| 状态历史 | `StatusHistory` | 对物品、申请、项目或捐赠状态变化追加的审计记录 |
| 站内通知 | `Notification` | 与业务事件关联、只在本校范围内可见的消息 |
| 审计日志 | `AuditLog` | 对关键管理、权限、状态和争议操作追加的安全记录 |

## 公益

| 中文术语 | 代码术语 | 定义 |
|---|---|---|
| 公益项目 | `CharityProject` | 具有目标数量、期限和接收对象的物资募集项目 |
| 公益需求项 | `CharityProjectNeed` | 公益项目下某一种物资的目标数量、已接收数量和单位 |
| 捐赠记录 | `Donation` | 用户提交的实物捐赠记录 |
| 捐赠物资明细 | `CharityDonationItem` | 一次捐赠中的具体物资、数量、图片和核验数量 |
| 公益义卖 | `CharitySale` | 仅存在于总体设计、首版不开发的模拟义卖流程 |
| 微心愿 | `WishProject` | 公益项目的具体物资需求；首版只展示目标和进度 |
| 公益回执 | `CharityReceipt` | 接收组织或管理员提供的物资接收与发放证明 |
| 回执物资明细 | `CharityReceiptItem` | 回执中列出的物资名称、数量及可追溯来源 |

## 状态与限制

- 一个物品同一时间只能存在一个进行中的流转业务。
- 借用结束必须经过归还确认；出售、赠送和回收以各自交接完成作为结束。
- 公益募集数量不得超过目标数量。
- “已支付”在首版只表示模拟支付状态，不代表真实资金到账。
- “完成”只描述当前业务记录结束；是否允许重新上架由物品模式和当前状态决定。
