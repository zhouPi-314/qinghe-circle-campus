# 青禾流转文档目录

公开项目入口见仓库根目录 `README.md`。本目录保留开发阶段的决策、设计和实现证据；涉及基础设施账号 ID 的内容已做占位符脱敏。

## 阶段目录

| 目录 | 内容 |
|---|---|
| `0-pre-development/` | 问题定义、可行性、前置计划、已确认约束、部署评估与就绪清单 |
| `00-governance/` | 技术标准、术语、质量门禁、决策记录 |
| `6.1-requirements/` | 需求发散稿、删减表、需求规格、用例图、流程图 |
| `6.2-design/` | 总体设计、详细设计、数据库、UI、验收标准 |
| `6.3-development/` | 开发计划、技术方案、验证证据和已知限制 |

本地项目提交材料、生成脚本和内部工作记录不进入公开仓库，也不作为应用运行依赖。

## 唯一规则入口

- 项目级强制规则：`../AGENTS.md`
- 技术标准：`00-governance/engineering-standards.md`
- 开发门禁：`00-governance/collaboration-and-quality-gates.md`
- 业务术语：`00-governance/glossary.md`
- 变更记录：`00-governance/decision-log.md`
