## 1. 本轮结论

注册页增加图形验证码和手机号验证码在技术上可行，但不能把“真实短信”当作无成本的小改动。课程可验收版本应采用“服务端图形验证码 + 模拟手机验证码”，真实短信作为需要外部账号和生产配置的可选增强。

当前不建议立即接入真实短信，原因如下：

1. 阿里云官方接入说明给出的完整接入周期为 10–15 个工作日，包含资质、签名、模板和运营商实名报备；这已接近当前课程收尾窗口。
2. 阿里云国内验证码短信当前标价为 0.045 元/条起；腾讯云当前公开套餐约 0.047 元/条。验证码重发、攻击和测试都会产生真实费用。
3. 短信必须配置 AccessKey、签名和模板，密钥不能进入仓库；现有 `.env.example` 和 Vercel Secret 规则需要扩展。
4. 注册前发送短信会处理手机号。需要遵循《个人信息保护法》的合法、正当、必要、最小范围和告知原则，并限制来源 IP、手机号、学号和失败次数。
5. Vercel 无内存级限流保证，限流和验证码状态不能只放进程内存；需要数据库记录或外部缓存。

## 2. 推荐方案

### 方案 A：课程可交付版（推荐）

**图形验证码 + 服务端模拟手机验证码。**

- 图形验证码由服务端生成 SVG，答案只保存服务器密钥参与的 HMAC 摘要和过期时间，不保存明文。
- 图形验证码有效期建议 2 分钟；答错或过期后重新生成。
- 图形验证码通过后，才允许请求手机验证码。
- 手机验证码只在“学号、手机号与本校名单匹配”后生成；页面返回统一提示，避免公开探测某个学号是否存在。
- 手机验证码建议 60 秒重发冷却、5 分钟有效、最多校验 5 次、成功或过期后一次性失效。该有效期与现有“登录验证码 60 秒有效”不同，若采用需同步修订 SRS。
- 课程开发/演示环境在页面显示模拟验证码；生产环境不显示，只保留可配置的测试后门说明，且默认关闭。
- 新增数据库记录保存 `purpose`、名单记录标识、手机号 HMAC、验证码 HMAC、盐、过期时间、尝试次数和消费时间；不保存手机号或验证码明文。
- 注册事务只在验证码校验成功后执行；验证码消费和学生账号创建需在服务端完成。

优点：零外部费用、无运营商报备、GitHub 复刻不依赖第三方账号、可完整自动化测试。

### 方案 B：真实短信增强

在方案 A 上把“模拟发送”替换为阿里云或腾讯云短信适配器。

前置条件：

- 用户完成服务商实名认证，提供短信签名和模板审核材料。
- 取得服务器专用凭据，只放 Vercel Secrets 与本地 `.env.local`。
- 增加发送适配接口、服务商错误映射、发送量预警和费用上限。
- 完成隐私告知、用途说明、保留期限和删除机制。
- 使用生产手机号做少量端到端 smoke test。

该方案不能承诺在当前截止日前完成，原因是外部审核周期不由项目控制。

### 方案 C：仅加固现有名单核验

保留现有“学号与名单手机号必须匹配”，增加图形验证码、IP/账号/手机号维度的频控和审计，不发送短信。

优点：改动最小，能阻止大部分脚本化注册。缺点：与用户明确提出的“手机号验证码”不完全一致，因此只能作为降级方案。

### 方案 D：邮件验证码

不推荐。当前学生名单没有邮箱字段，会增加新个人信息的收集，且不能证明手机号归属。

## 3. 注册流程

```text
进入学生注册页
  → 输入学号、手机号、密码
  → 服务端校验基础格式与名单匹配
  → 生成并校验图形验证码
  → 发送/展示模拟手机验证码
  → 校验手机验证码、尝试次数和有效期
  → 创建学生账号并原子消费验证码
  → 清理同一名单记录的旧挑战
```

安全边界：

- 登录、注册与验证码请求继续使用 CSRF 防护。
- 验证码错误、过期、重发频繁、请求过快均返回可操作的下一步提示。
- 不记录完整手机号、验证码、数据库连接串或短信密钥。
- 不根据手机号是否已注册给出可枚举的公开差异。
- 在数据库事务或带唯一约束的记录中预占重发额度并写入 `pending`，发送成功后再更新服务商结果，避免并发请求穿透冷却。
- 同一手机号、IP 和名单记录均设置日限额；生产环境优先依赖服务商风控与平台侧双重限制。

## 6. 验收标准

1. 图形验证码未通过时，手机验证码接口拒绝请求。
2. 学号、手机号或校区不匹配时，不发送短信，不泄露名单细节。
3. 60 秒内重复请求被拒绝；验证码过期、错误次数超限和重复使用均不可注册。
4. 服务端不保存验证码或手机号明文；日志和测试报告不含敏感值。
5. 注册成功只创建一条学生账号，并原子消费名单记录和验证码。
6. 键盘用户可完成验证码刷新和输入；图形验证码提供清晰的状态说明。
7. 无短信服务配置时，课程版仍可启动、测试和本地复刻。
8. 真实短信方案启用后，失败发送不会创建账号，且费用上限、错误重试和审计可追踪。
