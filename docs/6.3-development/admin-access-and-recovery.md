# 公网平台管理员账号获取与恢复

## 1. 先说结论

公开网站不提供、也不应该提供“查询管理员密码”功能。当前生产账号密码只保存慢哈希，无法从公网页面、数据库哈希或 GitHub 仓库反推出明文。

默认管理员登录名通常是 `platform_admin`，但登录名不等于密码。若不知道生产密码，应由部署所有者通过受控数据库操作创建一个新的平台管理员，或重置现有账号密码。

## 2. 有 Vercel/Neon 管理权限时

适用于项目所有者、课程维护者或被明确授权的基础设施管理员。

1. 在 Neon 控制台确认生产数据库，在 Vercel Project Settings 确认 Secret 变量来源。不要截图或粘贴完整连接串。
2. 在本地 `.env.local` 中临时配置生产 `DATABASE_URL` 和同一个 `SECRET_KEY`，确保该文件位于 `.gitignore` 中。
3. 在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe tools\create_platform_admin.py --login-name recovery_admin --nickname "恢复管理员"
```

4. 按终端提示输入至少 8 位、同时包含字母和数字的新密码。命令只保存哈希，不把密码写入源码、命令历史或日志。
5. 登录 `/auth/login`，选择“平台管理员”，使用新账号验证管理页权限。
6. 完成后清除本地终端中的临时数据库配置；不要把 `.env.local`、连接串、密码或 Secret 提交到 Git。

本项目允许存在多个平台管理员账号，因此创建独立恢复账号比在 SQL 客户端手改密码更安全、更容易审计。若必须重置现有账号，应另行实现受控重置命令；当前首版没有管理员自助改密或“找回密码”页面。

## 3. 没有基础设施管理权限时

- 公开访客无法获取管理员账号，这是正确的权限边界。
- 请联系仓库所有者、部署所有者或课程维护者，通过 Vercel/Neon 权限和受控操作完成恢复。
- 不要在 Issue、Discussion、聊天截图或公开文档中提交密码、验证码、连接串、数据库导出或 Secret。
- 不要尝试通过公开注册页获得管理员角色；管理员账号由平台管理员创建。

## 4. 安全检查

- 恢复账号使用独立登录名和强随机密码。
- 确认公网 Cookie 仍为 `Secure`、`HttpOnly`、`SameSite=Lax`。
- 若怀疑密码泄露，先禁用旧账号，再新建恢复账号并检查审计日志。
- 不要通过轮换 `SECRET_KEY` 来解决管理员密码问题；轮换会影响手机号 HMAC，必须按 D-033 执行迁移。
