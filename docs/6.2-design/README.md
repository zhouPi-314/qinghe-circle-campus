## 4. 核心设计结论

- 概念模型最终得到 27 张有独立职责的表；数量来自建模结果，不以固定表数为目标。
- 四类流转共用 `circulation_requests`、`handover_records` 和 `status_history`，差异规则放入三张明细表。
- 登录按在校学生、公益管理员、平台管理员、校级管理员四类身份分流；只有学生可自主注册。
- 所有业务数据可以追溯到 `university_id`；同校跨校区允许，跨校访问在服务层拒绝。
- 四川省高校临时库包含教育部 2025 名单中的 141 所普通高校和 161 条校区记录。
- 关键状态变化、权限检查和事务提交由 service 统一负责，路由和模板只处理输入输出。
- 公益首版采用项目需求、捐赠、核验、回执和回执项目五层记录，不包含公益资金。
- UI 采用“青禾发现”方向，以中国校园主题视频、东亚人物、蓝青操作色、四类流转多选项和真实物品照片建立识别；公益页保留可暂停物资整理视频、授权场景图集与回执信息，发现页增加编辑式二次流转图文区和克制的悬停、交错显现动效。
- 登录身份使用下拉框选择；学生继续进入学校与校区流程，三类管理员直接进入对应登录页。
