## 2. 对本项目的取舍

- 保留中国校园视频作为发现页主视觉，用人物和校园环境替代深绿色装饰块。
- 恢复发现页的四类流转多选项，让学生先辨识“怎么流转”，再进入搜索和浏览。
- 物品列表与清单缩略图直接使用真实物品照片，避免连续同构色块；类别标签只承担识别，不替代图片或状态。
- 物品详情使用真实台灯照片；公益页使用公开授权的中国乡村课堂、中国小学课堂、淮安图书馆与旧书场景，并明确标注“场景示意”，不让场景照冒充真实项目成果。
- 公益页采用“目标与进度 + 可核验回执 + 场景图集”的组合，借 charity: water、亲青公益和 Kiva 的透明表达，而不是只做一个大色块和口号。
- 发现页新增编辑式“第二次被选择”图文区，借 Rainforest Alliance 的图像与文字交替节奏，避免整页都是同构卡片。
- 发现页和公益页各播放一段本地主题视频，并提供暂停/播放按钮；减少动效时只显示静态海报，不自动播放。
- 导航切换增加跨文档淡入；内容卡片使用短距离显现，进度条在进入视口时生长。所有动画都支持 `prefers-reduced-motion`。
- 身份选择改为下拉框，减少四个同构入口卡带来的模板感。
- 导航、搜索、筛选和操作按钮继续使用统一 SVG 图标；照片只承担叙事，不替代状态与权限信息。
- 不用外部站点的品牌、插画或页面截图作为项目素材。

## 4. 共同规律与本项目边界

1. 现代公益与内容站通常先用一个强场景建立情绪，再立刻给出项目目标、进度、行动或故事入口。
2. 图片不能只当背景。有效案例都给图片安排明确任务：建立人物、说明项目现场、展示物品，或证明结果。
3. 导航和筛选必须像工具，叙事区才像杂志。把业务操作做成海报会降低可用性。
4. 动效集中在入口显现、状态反馈、图片轻微位移和结果增长；持续漂浮、闪烁和无法暂停的背景运动不采用。
5. 本项目只借鉴信息节奏、图片与文字比例、数据透明表达和动效用途，不复制外部站点的品牌、版式、图标、插画、文案或页面结构。

## 5. 本轮交互与素材边界

- 闲鱼、Good On You、Ellen MacArthur、Figma Education、Duolingo、Khan Academy、UNICEF、UNDP、上海真爱梦想公益基金会和亲青公益详情页均实际滚动并查看主要子页或中下部内容。
- 亲青公益“希望工程 1+1”详情页可正常查看目标金额、已筹金额、参与人次、备案编号、项目进展和反馈入口；本次没有点击捐赠，也没有提交个人资料。
- UNICEF 与 UNDP 只用于学习公益行动入口、服务条件和证据表达；没有下载或复用联合国网站摄影素材。
- 外部网站截图仅作为内部评审证据，不进入公开文档正文，也不作为本项目宣传素材。

## 6. 素材来源

当前原型采用的 Pexels 图片与视频、作者、素材页、许可证、修改方式、模型授权提示和“场景示意”限制全部记录在 `assets/credits.json`。人物素材优先来自中国大陆与东亚场景，界面文字保持简体中文。场景素材只作设计评审示意，发布前仍需重新核对人物、商标、场所与公开发布范围；涉及未成年人的课堂照片不得直接用于公开募捐宣传。
