## 1. 数据范围

首批高校目录来自教育部 2025 年全国普通高等学校名单，共录入四川省普通高校 141 所。学校名称、学校标识码、办学层次、办学性质和主管部门以该名单为准。

数据文件包含 161 条校区记录。每所高校至少有一条主校区记录：

- 10 所已核验多校区高校记录为 `official`，校区名和官网来源同时保存。
- 其余高校暂以学校全称作为单校区名称，记录为 `temporary`。
- 在 UI 中，单校区高校的校区选择直接显示学校全称。

## 3. 数据规则

- `school_code` 使用教育部学校标识码，不自行编造。
- `education_level`：`undergraduate` 表示本科，`college` 表示专科。
- `ownership`：`public` 表示公办，`private` 表示民办。
- `education_level` 在登录页显示为“本科/专科”；`ownership` 等办学性质属性只用于基础数据维护，不在学生学校选择页展示。
- `verification_status=official`：校区记录已对照学校官网。
- `verification_status=temporary`：单校区占位仍待逐校核验。
- 学校或校区停用时不物理删除，更新 `status`。

## 4. 更新流程

1. 从教育部最新普通高等学校名单确认学校名称和标识码。
2. 从学校官网确认校区名称、地址和启用状态。
3. 更新 `data/sichuan_universities_2025.csv`。
4. 运行高校数据生成脚本，更新种子 SQL 和原型高校列表。
5. 在临时 PostgreSQL schema 中重新执行 `schema.sql`、`seed.sql`。
6. 记录变更日期和数据源链接。

## 5. 限制

- 校区名称会随学校布局调整变化，临时记录不得当作正式认证依据。
- `temporary` 记录只保证可用于当前原型，不得在正式页面、对外数据或认证结论中标记为“已核验”。
- 全国高校库和真实高校认证仍是后续功能，首版只使用本地导入数据。
- 高校名单不包含真实学生名单，平台注册仍需管理员单独导入学生数据。
