- 四类登录身份均可到达对应登录页。
- 学生登录前可选择学校、校区。
- 高校选择使用一体化输入下拉，141 所高校位于同一控件中，可直接输入关键词搜索。
- 原型共 12 个页面状态，截图脚本覆盖 18 个桌面、移动端和身份组合视图。
- 375、390、768、1024、1440 五个宽度下的发现、身份、学校、详情、登录、发布、公益和后台页面均无横向溢出。
- 共 58 个浏览器渲染检查全部通过：无横向溢出、缺失主区域、未关联表单控件或过小交互目标。
- 五所示范高校的校徽均按实际图形裁边并居中，徽章图片与 44×44 CSS 像素圆框同宽高，`object-fit` 为 `cover`。

- 桌面按钮、导航、筛选和移动端底部导航的交互目标均不小于 24×24 CSS 像素。
- 四类身份入口完整可达；学生登录显示“前往注册”，三类管理员登录均不显示注册入口。
- 身份入口通过下拉框完成选择；选择公益管理员后可正确进入对应登录页。
